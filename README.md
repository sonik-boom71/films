# Киноподборка на Python

Небольшой сайт с рекомендациями фильмов на **Flask**.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

После запуска откройте: http://127.0.0.1:5000

## Как работает

- Вы выбираете жанр и настроение.
- Сайт подбирает подходящие фильмы из встроенной базы.
- Если фильтр слишком строгий и совпадений нет, алгоритм ослабляет условия и всё равно предлагает варианты.
